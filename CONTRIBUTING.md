# Как внести вклад

Спасибо, что хотите помочь. Репозиторий маленький, правила простые.

## Что приветствуется

- Новые источники вакансий с проверенными URL и параметрами.
- Улучшение формулировок `SKILL.md` без раздувания файла.
- Новые кейсы в `evals/cases.json`.
- Исправления опечаток и битых ссылок.
- Переводы.

## Чего не принимаем

- Скрейпинг и обход капчи.
- Автоматические отклики и отправку резюме от имени пользователя.
- Сбор персональных данных.
- Выдуманные вакансии, компании и зарплаты в примерах.

## Перед pull request

```bash
python scripts/check_contract.py
python -m unittest discover -s tests -v
```

Если установлен Claude Code, дополнительно:

```bash
claude plugin validate . --strict
```

Оба скрипта должны завершиться успешно. Если меняете `SKILL.md`, проверьте, что:

- frontmatter `name` и `description` не изменились без причины (от description зависит активация скилла);
- правила из раздела «Правила» остались на месте;
- новые источники описаны в `references/sources.md`, а не только в промпте.

Если меняете версию, обновите её сразу в трёх местах: `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `CHANGELOG.md`.

## Стиль

- Русский язык, обращение на «вы».
- Короткие абзацы, таблицы вместо длинных перечислений.
- Без маркетинговых обещаний, которые нельзя проверить.
