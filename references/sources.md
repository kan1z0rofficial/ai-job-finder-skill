# Источники и параметры поиска

Справочник для агента: как строить ссылки и что проверять в выдаче. Основной источник — hh.ru; остальные используются как дополнение.

> URL-параметры площадок меняются без предупреждения. Если ссылка открывается, но фильтры не применились — откройте страницу поиска и настройте фильтры вручную, затем используйте получившийся URL.

## hh.ru

Базовая ссылка:

```text
https://hh.ru/search/vacancy?text=...&area=...&experience=...&schedule=...
```

| Параметр | Значение | Пример |
|---|---|---|
| `text` | поисковый запрос | `Python-разработчик` |
| `area` | id региона | `1` — Москва, `113` — вся Россия |
| `experience` | `noExperience`, `between1And3`, `between3And6`, `moreThan6` | `between1And3` |
| `schedule` | `fullDay`, `shift`, `flexible`, `remote`, `flyInFlyOut` | `remote` |
| `employment` | `full`, `part`, `project`, `probation`, `volunteer` | `full` |
| `salary` | минимальная зарплата, число | `200000` |
| `currency_code` | валюта зарплаты | `RUR` |
| `only_with_salary` | только с указанной зарплатой | `true` |
| `order_by` | `relevance`, `publication_time`, `salary_desc`, `salary_asc` | `publication_time` |
| `search_field` | `name`, `description`, `company_name` | `name` |
| `items_on_page` | `20`, `50`, `100` | `50` |
| `page` | номер страницы с нуля | `0` |

Синтаксис `text`:

- `"точная фраза"` — поиск фразы целиком;
- `!слово` — точная словоформа;
- `OR` — альтернатива: `сварщик OR монтажник`;
- `NOT` — исключение: `водитель NOT продажи`.

Пример: `text=водитель NOT "сетевой маркетинг"`.

### Что читать в выдаче

- **Зарплата**: «от» / «до» / «вилка»; «на руки» или «до вычета»; за месяц, смену или час. Приводите к месячной сумме и помечайте характер.
- **Опыт**: «без опыта», «1–3 года», «3–6 лет», «более 6 лет».
- **Формат**: удалёнка, гибрид, офис, вахта, смены. У вахты — длительность и ротация (`60/30`, `30/15`), если указаны.
- **Дата**: когда опубликована вакансия и обновлялась ли она.

## API hh.ru

Официальный поиск: `https://api.hh.ru/vacancies`.

```text
GET https://api.hh.ru/vacancies?text=сварщик&area=95&per_page=20&page=0
User-Agent: ai-job-finder-skill/1.2 (contact)
```

Параметры совпадают с сайтом: `text`, `area`, `experience`, `schedule`, `employment`, `salary`, `currency`, `only_with_salary`, `order_by`, `search_field`, `per_page` (до 100), `page` (с 0).

Особенности:

- API может требовать токен приложения. Токен передаётся заголовком `Authorization: Bearer <token>`; скрипт `scripts/hh_api.py` берёт его из `--token` или `HH_ACCESS_TOKEN`.
- Без токена возможен ответ `403 forbidden`. Это не повод обходить защиту: переключитесь на веб-поиск.
- При `429` API просит подождать; скрипт делает одну повторную попытку с `Retry-After`.
- `User-Agent` обязателен и должен содержать название приложения и контакт.
- Официальный API отдаёт только публичные вакансии и не требует авторизации пользователя.

Маппинг ответа в схему `references/output.md`:

| API | Схема |
|---|---|
| `id` | `hh-<id>` |
| `name` | `title` |
| `employer.name` | `company` |
| `area.name` | `city` |
| `salary.from` / `salary.to` | `salary_from` / `salary_to` |
| `salary.currency` | `currency` |
| `salary.gross` | `gross` |
| `experience.id` | `experience` (`noExperience` → `none`, `between1And3` → `1-3`, и т.д.) |
| `schedule.id` | `work_format` |
| `alternate_url` | `url` |
| `published_at` | `published_at` (дата без времени) |

Скрипт: `python scripts/hh_api.py --text "Python" --area 1 --limit 20 --format json`.

## Rabota.ru

```text
https://www.rabota.ru/vacancy/?query=сварщик
```

Проверьте, что фильтр по региону применился: у площадки регион часто задаётся отдельным сегментом URL. Если сомневаетесь — откройте главную, выберите регион и профессию вручную и скопируйте итоговую ссылку.

## SuperJob

```text
https://russia.superjob.ru/vacancy/search/?keywords=сварщик
```

Для конкретного города домен может отличаться (`https://www.superjob.ru` и региональные поддомены). Проверяйте, что в выдаче нужный город.

## Авито Работа
```text
https://www.avito.ru/rossiya/rabota?q=сварщик
```

Для города сегмент `/rossiya/` заменяется на slug города, например `/tyumen/`. Slug проще получить, открыв Авито Работа и выбрав город вручную.

Авито сильнее всего для рабочих специальностей, вахты и сменных графиков.

## Правила обработки результатов

1. **Приоритет источников**: hh.ru → Rabota.ru → SuperJob → Авито. Если на hh.ru нашлось 10+ релевантных вакансий, остальные площадки можно не открывать.
2. **Дедупликация**: одна и та же вакансия на разных площадках показывается один раз, источники перечисляются через запятую.
3. **Проверка первоисточника**: зарплата и опыт берутся со страницы вакансии, а не из сниппета поисковика.
4. **Свежесть**: в итоге всегда указывается дата поиска в формате `ГГГГ-ММ-ДД`. Вакансии старше месяца помечайте как «может быть неактуальна».
5. **Пустая выдача**: не подменяйте результат выдуманными вакансиями. Сообщите, что не найдено, и предложите 2–3 альтернативных запроса (смежная профессия, соседний город, снятие фильтра по зарплате).
6. **Зарплата не указана**: пишите «не указана», не оценивайте по рынку.

## Чего не делать

- Не строить циклы запросов по десяткам страниц: это похоже на скрейпинг и приводит к капче.
- Не обходить капчу и защиту площадок.
- Не откликаться на вакансии и не отправлять резюме от имени пользователя.
- Не собирать и не пересылать ФИО, телефон, email и другие персональные данные.
- Не выдавать ссылки, которых не было в выдаче или которые не собраны скриптом.
