# 📖 Руководство: установка и использование ai-job-finder-skill

## Что делает этот скилл

Скилл превращает любого AI-агента в помощника по поиску работы. Вы пишете агенту, кем и где хотите работать — он ищет актуальные вакансии в интернете и выдаёт аккуратную таблицу с зарплатами, опытом и ссылками на источники.

**Поддерживаемые форматы работы:** офис, удалёнка, гибрид, вахта, сменный график.

**Источники вакансий:** hh.ru, Rabota.ru, SuperJob, Авито Работа.

## Как пользоваться (примеры)

После установки напишите агенту обычными словами:

```
Найди мне работу сварщиком в Тюмени, вахта, опыт 3 года, от 150к
```

```
Ищу бухгалтера, удалённо, без опыта
```

```
Найди вакансии Python-разработчика в Казани, гибрид, 200–300к
```

**Что произойдёт:**
1. Если чего-то не хватает (например, формата работы), агент задаст один уточняющий вопрос.
2. Агент выполнит поиск по сайтам вакансий.
3. Вы получите таблицу до 10 вакансий: должность, компания, зарплата, опыт, город/формат, источник.
4. Плюс итог: сколько найдено всего, медианная зарплата, дата поиска и совет, как улучшить запрос.

## Установка по платформам

### 1. Claude Code

```bash
mkdir -p ~/.claude/skills/ai-job-finder-skill
cp SKILL.md ~/.claude/skills/ai-job-finder-skillh/
```

Перезапустите Claude Code. Скилл активируется автоматически при запросах про поиск работы.
Для одного проекта вместо `~/.claude` используйте папку `.claude` в корне проекта.

### 2. Claude Projects (claude.ai)

1. Откройте ваш Project на claude.ai.
2. Перейдите в **Project knowledge**.
3. Загрузите файл `SKILL.md` (Upload).
4. Готово — Claude будет следовать инструкциям скилла в рамках проекта.

### 3. OpenClaw

```bash
mkdir -p ~/.openclaw/skills/ai-job-finder-skill
cp SKILL.md ~/.openclaw/skills/ai-job-finder-skill/
```

Путь к скиллам можно изменить в конфиге агента (`skills.dir`).
Перезапустите агента — скилл подхватится автоматически.

### 4. Codex (OpenAI)

Скопируйте **содержимое** `SKILL.md` в файл `AGENTS.md` в корне вашего проекта:

```bash
cp SKILL.md AGENTS.md
```

Codex прочитает инструкции при старте сессии в этом проекте.

### 5. ChatGPT (Custom GPT)

1. На chat.openai.com нажмите **Explore GPTs → Create**.
2. В поле **Instructions** вставьте содержимое файла `SKILL.md`.
3. Сохраните GPT. Теперь он умеет искать вакансии по вашим параметрам.

### 6. Kimi и другие агенты

- Если агент поддерживает скиллы — поместите `SKILL.md` в его папку скиллов.
- Если нет — просто вставьте содержимое `SKILL.md` в начало диалога или системный промпт.

### Быстрая проверка

После установки напишите агенту: **«Найди работу менеджером по продажам в Москве, офис, от 100 тысяч»**. Если агент вернул таблицу вакансий с источниками — всё работает ✅

## Параметры поиска

| Параметр | Обязателен | Пример |
|---|---|---|
| Профессия | ✅ | «токарь», «аналитик», «грузчик» |
| Город | ✅ | «Сургут» (для удалёнки — «по РФ») |
| Формат работы | ✅ | офис / удалённо / гибрид / вахта / смены |
| Опыт | нет | «без опыта», «3 года» |
| Зарплата | нет | «от 120к» |
| График | нет | «2/2», «5/2» |

## Возможные проблемы

| Проблема | Решение |
|---|---|
| Агент не активировал скилл | Проверьте путь установки и перезапустите агента |
| Вакансии не находятся | Ослабьте фильтры: уберите зарплату/опыт, расширьте город |
| Старые вакансии в выдаче | Скилл всегда пишет дату поиска — применяйте результаты оперативно |
| Агент «галлюцинирует» вакансии | Напишите ему: «показывай только вакансии из найденных источников» |
